# Atelier 🎨

Atelier is a visual, beginner-friendly learning studio for traditional painting techniques.

## Current MVP
- Óleo, acrílico, oil pastel, acuarela y lápiz de color.
- Personalized project builder.
- Visual technique selector.
- Step-by-step workflow from analysis to finishing.
- Materials, palette and technique-specific guidance.
- Progress checklist persisted in localStorage.
- Responsive editorial interface designed for artists and art students.

## Product direction
Atelier is designed around the experience of *“I have a reference I love, but I don't know how to turn it into a painting.”*

The next product layer will add image/reference analysis so a user can upload a reference and receive:
1. composition + drawing map
2. light/value map
3. suggested palette
4. useful mixtures
5. technique-specific step sequence
6. checkpoints and correction prompts
7. visual progress comparisons

## Run
This MVP is a zero-build static app. Open `index.html` or deploy it directly to Vercel.
